# 0. CORE PROJECT

PackRAG-MoR is an offline Android specialist AI architecture composed of:

- the official pretrained **360M expert-choice Mixture-of-Recursions (MoR)** generator;
- a modular PackRAG retrieval runtime;
- independently installable signed `.kpack` Knowledge Packs;
- source-grounded generation;
- citations;
- abstention;
- offline operation;
- no cloud inference requirement.

The research question is:

> Can an ultra-small adaptive-compute language model become a useful offline specialist when factual memory, provenance, versioning and retrieval structure are moved into independently installable signed Knowledge Packs?

MoR remains the primary research model.

The product must NOT depend on MoR Android deployment succeeding.

v1.2 therefore also defines a product-continuity fallback:

```text
HuggingFaceTB/SmolLM2-360M-Instruct
```

using:

```text
llama.cpp / GGUF
```

as the preferred Android runtime.

The fallback is not the research contribution.

It exists so Android product completion is never blocked by experimental MoR deployment.
