This is a new versioned iteration after the accepted F1 checkpoint and passing F2 API, fault/cancellation and actual importing-subprocess recovery iterations. It does not complete F2, M4 or the product. Final domain packs remain owner supplied. Original historical experimental output is unchanged.

`prepare_full_sources.py` installs the selected0066 APK pair with `adb install -r`; it does not uninstall or clear data. It measures available private space and requires two complete2009206667-byte asset sets plus64MiB. It fails before reading/traversing or modifying any existing `files/f2-full-assets-0001` namespace. Under the test UID it creates that one flat namespace with an exact ASCII ownership marker, then copies only the four already pinned owner model paths on the phone. The shell pipeline has `pipefail` enabled and independently demonstrates a failing upstream process yields a nonzero pipeline status. Both run-as commands' combined pipeline success is required. The sink uses noclobber creation, writes only its fixed newly owned filename, and produces no stdout; no model byte passes into a host output file or pipe. Every source owner path's ancestors and leaf are checked against links, exact size and SHA before copying. Each new test-UID source is mode400 and the complete root becomes mode500. Validation checks root/marker/no-follow types, exact marker length/content, a flat exact whitelist, exact sizes and whole-file SHA256 for all four. Failure preserves the attempt and holds subsequent tests; it never deletes/reuses an unknown namespace automatically.
