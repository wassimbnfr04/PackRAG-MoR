# ADR-006: measured guide context/output budget revision

Status: owner-authorized runtime revision experiment, not promoted. 2026-10-12. Depends on ADR-005.

Rc9 repairs final grammar truncation after inline citations, but full frozen comparison records FAN_PARAPHRASE output-limit1024 with940 actual reasoning tokens and only84 final/terminal tokens. The partial guide is correctly unusable. Raising output to1536 inside the original2048 context cannot give that prompt its complete budget: prefill970 leaves1078. A larger context is therefore a correctness dependency, not a timing optimization.

Test mobile-v1-guides-rc10 with context3072 and generated1536, still prefill1536/evidence1200/max4 selected chunks and remaining-context clipping. Retain original model, official pinned template/BOS/open-think, real privately generated reasoning, greedy sampling, security role, retrieval and frozen inputs. Do not inject a closing reasoning token, fabricate completed reasoning, switch to undocumented no-thinking behavior or relabel a partial final accepted. An added generic procedural preservation rule asks for every documented check/caution in full-guide questions; no question-specific cache or evidence edits.

This explicitly deviates from v1.3's2048/512 limits and ADR-005's initial2048/1024 prototype. Exact baseline remains available and historical outputs immutable. The isolated launcher changes only its owned server context and retains exact binary/model/template pins, refusal of an unowned existing port, verified PID cleanup and original command/resource identity. Pilot checks the failed long paraphrase and full fan/tube instructions; full frozen comparative and semantic/security validation must pass before public API/native integration.

Production promotion additionally requires honest context/profile/grammar identities, independent baseline/revision contract coverage, desktop/Android token and decoder parity, actual newly pinned JNI and physical functionality/resource checks. Larger KV/context costs must be observed on the Samsung; no claimed memory or performance benefit. The existing model fits are not proof of the new context acceptance. Final owner packs/calibration/held-out gold remain outside M4. A generic policy cannot prove semantic entailment and reported guide adequacy remains bounded to recorded comparisons.
