## Production layout





New production source is isolated under `product/`: Python `packrag` library/CLI, configuration, clean Android multi-module application, pack specifications and tests. Existing research/baseline sources and outputs remain in their current paths. Reuse only audited format/test assets or exact pinned tools/models; do not import historical experiment runners into the product graph. The small tested legacy KPack validator is a reference for migration, not proof that the new full release lifecycle is implemented.

Release publisher key handling must exclude private keys from Android/public artifacts. Source redistribution permissions, genuine human translation review and manually verified benchmark/calibration gold must be evidenced, never invented. Physical acceptance requires the actual connected phone. Existing owner instruction to keep mobile data on is retained; v1.3 defines local operation/no-INTERNET as mandatory and airplane demonstration as SHOULD/optional, not a model-capability blocker. No global thermal/security/radio bypass is authorized.
